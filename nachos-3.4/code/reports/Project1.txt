How to Build & Run

Kept DEFINES in the Makefiles so graders can enable any exercise with:

make 'DEFINES=-DTHREADS -DCHANGED -DHW1_ELEVATOR'

Binary is built at:

code/threads/nachos

Run example:

cd code/threads
./nachos -rs 7
